# UniCryptoPay

A university campus cryptocurrency payment platform.

## Frontend
- Angular app in `/frontend`
- Run:
  - `cd frontend`
  - `npm install`
  - `npm start`

## Backend
- Node.js + Express

## Blockchain
- Ethereum private network
- Solidity smart contracts

## Docs
- Proposal content is available in `/docs`
- The frontend links to documentation pages from the app
